# research/

Measurements that informed a design decision, kept so the decision can be
re-checked rather than re-argued.

Each subdirectory holds runnable scripts plus a README with the numbers they
produced, the machine they were produced on, and what was concluded. If you
disagree with a decision recorded in `CLAUDE.md`, re-run the relevant script
before changing it — several of these overturned an assumption that looked
obviously true.

| Directory | Question it answers |
|---|---|
| `xdebug-overhead/` | What does per-test Xdebug instrumentation actually cost, and can per-test counts be collected at all? |
